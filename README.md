## 🚀 Projetos em destaque

### ⛪ Church Connect

Plataforma web desenvolvida para comunicação, gerenciamento de conteúdo e administração de uma comunidade religiosa.

O projeto combina uma **experiência pública responsiva** com um **painel administrativo**, permitindo controlar diferentes áreas da aplicação.

**Principais funcionalidades:**

- Dashboard administrativo
- Gestão de membros
- CRUD de testemunhos
- CRUD de obras missionárias
- CRUD de ministérios
- Pedidos de oração
- Programação e eventos
- Central de notificações
- Rotas protegidas
- Configurações institucionais
- Interface responsiva para desktop, tablet e mobile
- Integração entre painel administrativo e área pública

**Tecnologias:**

`Angular` `TypeScript` `RxJS` `HTML` `CSS` `Git` `GitHub` `Vercel`

🌐 **Demo:** https://church-connect-ruddy.vercel.app/  
💻 **Código:** https://github.com/LuizBarcelar/church-connect
